# Equalizer Landing Page

This is a solution to the [Equalizer landing page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/equalizer-landing-page-7VJ4gp3DE).

- [Live Demo URL](https://ionstici.github.io/equalizer-landing-page)
- [Submitted on Frontend Mentor](https://www.frontendmentor.io/solutions/equalizer-landing-page-hF8K2xJCGU)

This project was built while I was learning HTML and CSS, so the code source is "beginner-level". It is a simple, responsive landing page designed for a system audio equalizer application. The layout includes key sections like the product overview, pricing details, and download buttons for iOS and Android.
